# PixApp — UI gerada e refinada

Projeto: `pix-app/` (Angular CLI). Servir: `ng serve` → `http://localhost:4200`.

Material de design (não só código):

| Pasta | Conteúdo |
|-------|----------|
| `briefing/` | branding, figma-specs, google-stitch |
| `prompts/` | figma-to-angular, design-tokens, a11y, correção CSS, menu extrato, comprovante |
| `stitch/` | saída Stitch |
| `imagem/` | referências visuais |

Fluxo da aula: briefing → Stitch/Figma → código Angular → refino por prompt (tokens, a11y, CSS).
