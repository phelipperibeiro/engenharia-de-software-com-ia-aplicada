# Os 9 contratos (Aula 03)

Ordem da aula: **identidade → ciclo → decisão → capacidades → registro → execução → limites → observação → memória**.

| # | Arquivo | Pergunta |
|---|---------|----------|
| 1 | `agent.md` | Quem é o agente? |
| 2 | `contracts/loop.md` | Como ele cicla? |
| 3 | `contracts/planner.md` | Como decide? |
| 4 | `skills.md` | O que sabe fazer? |
| 5 | `contracts/toolbox.md` | Quais tools estão no recorte? |
| 6 | `contracts/executor.md` | Como valida e executa? |
| 7 | `rules.md` | Quais limites? |
| 8 | `hooks.md` | O que observar em cada ponto? |
| 9 | `memory.md` | O que guardar ou descartar? |

YAML dentro do Markdown é o contrato de máquina. O runtime (aula 04) lê esses blocos — não o texto livre.

Agente desta aula: `monitor-agent` (`task_based`, objetivo `resolver_incidente`).
